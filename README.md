# 第一段考後複習工作紙（高三理數學）

依第一學段考試卷的知識點整理的六張複習工作紙，每張對應一堂課的複習內容：

1. 導數的概念與基本求導公式
2. 求導法則：乘積、商、鏈式法則與二階導數
3. 導數的幾何意義：切線斜率與切線方程
4. 導數的應用：單調性、極值、最值與拐點
5. 不定積分與定積分的計算
6. 定積分的應用：面積與黎曼和

網頁版共 103 張重點頁：每章先有重點回顧（含可拖動的滑桿圖），再逐題列出工作紙的選擇題、填空題與解答題。解答預設收起，解答題按小題拆頁，可用步驟滑桿逐步看解法。

- 線上閱讀：開啟 `index.html`（GitHub Pages）
- 工作紙（學生版 Word）：`downloads/段考後複習工作紙_學生版.docx`

## 公式來源

瀏覽器無法直接顯示 Word 方程式（OMML）。本站工作紙題目、選項、答案與詳解的公式，皆由教師版 Word 工作紙中的 OMML 以程式轉成 TeX，再用本地 MathJax 3.2.2 顯示，並未另行手打。重點回顧頁與提示中的補充公式，先轉成 OMML（收錄於 `downloads/網頁版補充公式.docx`），再轉成 TeX 顯示。滑桿上的即時數值與圖中刻度是純文字。
